# Security policy

## Supported versions

This repository is an MVP. Security fixes are made on the default branch only.
There are no supported release branches yet.

## Reporting a vulnerability

Do not include proof-of-concept credentials, AAP URLs, Vault addresses, or
customer information in a public issue.

Use GitHub's private vulnerability reporting feature from the repository's
Security tab when it is enabled. If private reporting is unavailable, contact
the maintainer privately through GitHub and include:

- a description of the issue and its impact;
- the affected commit or version;
- concise reproduction steps; and
- any suggested mitigation.

The maintainer will acknowledge a report, assess it, and coordinate a fix
before public disclosure when practical.
